Examples: 1.10.10.0/24 · 2409::1/48

A prefix gets an exact match (or the longest covering prefix if there is none); an address gets the longest match. More-specific prefixes are listed for prefixes shorter than /24 (IPv4) or /48 (IPv6), since longer routes are normally filtered. AS names come live from RIPEstat; if that fails, from RIPE NCC's AS names list (shown in italics).

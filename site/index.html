How it works

  • ris-routing-data turns RIS dumps and 5-minute updates into an hourly routing snapshot, published as GitHub Releases.
  • rpki-aspa-data publishes validated ASPA objects.
  • aspa-validation combines both into ASPA verdicts.
  • This site downloads those releases every hour, splits them into small files by address block and serves them as static pages (source).
Routing data: RIPE NCC RIS. Times are IST (UTC+05:30).
